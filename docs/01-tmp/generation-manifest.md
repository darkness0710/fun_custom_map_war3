# Equipment icon generation manifest

Generated with the built-in image generation workflow. Each icon uses the
matching Mortal item as its style reference. File convention:

`<slot>/NN-<realm>-<slot>.png`

Progression palette:

- 01-05: mortal materials, pale-blue qi, cyan runes, compact gold and spirit light.
- 06-10: deep blue, violet void, body-integration metal, ascension crystal, tribulation lightning.
- 11-15: white jade, celestial blue-white, radiant gold, bagua light, Great Luo mandala.
- 16-20: imperial crimson, saintly white flame, dao script, primordial chaos, world-creation cosmos.

Status: complete. Eight equipment folders contain 20 PNG icons each (160 total).
